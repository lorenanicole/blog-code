# blog-code

Code, scripts and projects from **[lorenamesa.com](https://lorenamesa.com)** blog posts by [Lorena Mesa](https://lorenamesa.com).

Each folder maps to a post. The README inside each folder links back to the published article.

| Folder | Post |
|---|---|
| [`same-resume-different-agenda/`](./same-resume-different-agenda/) | [Same Résumé, Different Agenda: What AI Negotiation Coaches Assume About You](https://lorenamesa.com/same-resume-different-agenda.html) |

## Philosophy

- Code here is meant to be readable and runnable, not production-hardened
- Every number in a post that came from code has a corresponding script here
- Mock/synthetic runs are labeled clearly and never presented as real model results
- Dependencies are pinned in `requirements.txt` per project
